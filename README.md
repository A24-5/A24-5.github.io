# LEARNEO — Portfolio motion design

Site vitrine des réalisations en motion design de **Johnlex DOHOUNON** (LEARNEO) : publicités animées, vidéos explicatives, contenus de sensibilisation en santé publique et contenus éducatifs sur l'IA.

🌐 **Voir le portfolio : https://a24-5.github.io**

## Contenu
- `index.html`, `style.css`, `app.js` : le site (intro animée du logo, filtres, lecteur vidéo).
- `projects.js` : la liste des réalisations (titre, client, description, format, durée).
- `<id>.mp4` : les vidéos en version web légère ; `<id>.jpg` : leur vignette.
- `learneo-logo.mp4` : l'animation du logo LEARNEO jouée à l'ouverture ; `logo.png` : le logo.

## Ajouter une réalisation
1. Déposer la vidéo `mon-projet.mp4` et son image `mon-projet.jpg` à la racine du dépôt.
2. Ajouter une entrée dans `projects.js` avec `id: "mon-projet"`.
